# VRDex cloud startup

Read [the cloud task startup guide](../../../docs/engineering/cloud-task-start.md) before starting services or using hosted bindings. Choose the local or hosted lane from the task's intent, then follow that lane's readiness checks. The guide is the startup source of truth; workspace copies from earlier setup sessions are historical captures.
