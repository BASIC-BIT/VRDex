## ELF, aliases and named-object identity

`parseElfIdentity` in `scripts/event-marker-runtime-observer.mjs` parses actual complete bytes: ELF64 little-endian, machine 62, ELF type, interpreter, DT_NEEDED list in order, RPATH, RUNPATH, SONAME and GNU build ID. It bounds program headers at 256, validates offsets/sizes, dynamic termination and strings and rejects duplicate/conflicting note/dynamic facts. Pin all returned fields, including absent values. Version banners alone do not identify the executable or libraries.

`namedObject` checks each declared link target, lstat regular/non-symlink canonical file, full length/hash and before/after dev/ino/size/mtime/ctime, then compares actual ELF identity to the catalog. The actual observation adapter must preserve full-body acquisition and all existing caps/deadlines. `prepareInvocationObserver` resolves both ffmpeg and ffprobe through the approved absolute PATH before launch and requires their actual canonical paths. The profile cannot rely on an earlier shell resolution or a different binary with a matching version string.

`assertCatalogAlias` proves each admitted alias reaches the canonical object using declared prefix links, at most 16 steps, without cycles. Retain every link path and target exactly, including directory aliases. The catalog must explain executable paths, mapped aliases and loader names in the actual image. Relative link targets are interpreted by the existing POSIX path rule, not by convenient string equality. Complete named files and their linkage are independently rechecked after the child; disappearance, modification or changed targets fail.

A named-file hash plus proc maps is conditional evidence under the approved kernel/filesystem/loader view. It does not establish identity of every executable page. This source uses stable named aliases under approved mounts; it deliberately retains overlay device/inode disagreements rather than replacing them with fabricated equality. Review must state why the named-file/mapping association is acceptable under the actual platform assumptions and retain raw disagreement facts.
