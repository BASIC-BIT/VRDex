## How these guards establish conditional evidence

All thirteen guards are required together. The table below is this successor's mapping to actual enforcing functions and operands. It does not assert knowledge of missing R85 row wording. Existing source attaches explicit G labels to some checks; shared conservation helpers often throw `marker_program_conservation`, and construction helpers throw `marker_source_*` rather than a G label. In particular the G4 construction obligation below maps to actual unlabelled construction/feed checks. Error-label equality is not proof of semantic coverage.

Native algorithm semantics are conditional premises that require full pinned upstream source/build/provider originals and real semantic review under the pins authority. Local JavaScript replay plus log observations cannot independently prove native implementation or complete dynamic loading. Every description must name its complete semantic review and applicable source originals. A generic “approved” body or hash-only digest cannot satisfy those premises.

After adoption G0/G12 must carry all five exact complete authority refs; G1–G11 each also carry the new guards ref. Actual exact-body review, adoption and subsequent exact implementation/semantic review are required through proof/catalog/K and A's complete matching audit set. Mandatory full refs have no `range` property. These strengthened membership obligations are intended implementation work, not a claim that baseline code already enforces five originals. At baseline `validateProgramDependencies` explicitly checks only the R94 fixed original at G0/G12; this deficiency is the bounded recovery change.

## Complete finite media operands

Inventory is over the entire admitted TS file, at most 5242880 bytes in `verifyProgramRecording`. Physical packets, table sections, PES payload spans and elementary bytes must be complete. Video has one SPS with POC type 2, one AU per PES, DTS equal PTS, identity presentation order, AUD primary picture type 7, exact AUD prefix and admitted NAL start-code lengths. Each AU's complete source spans must hash to the original bytes. Audio PES contains complete ADTS frames with exact start/end and no dropped suffix; local frame PTS advances by 1920 and stays below the admitted wrap range. Unknown grammar fails rather than selecting another demux model.

For F source frames and N stereo input samples, require K = `ceil(N/1024)+1` AAC units and M = `1024*K` decoded samples. Encoder video input frames/packets equal F and bytes equal the raw source; output frames/packets equal F with exact mux payload bytes. Encoder audio input bytes/samples equal `4*N`/N, packets equal frames; encoded audio frames are `ceil(N/1024)`, samples N, packets K and exact AAC mux bytes. Decoder input video frames/packets F and complete elementary byte count, audio frames/packets K and M samples; decoder output video F frames/packets and `6*F` RGB bytes, audio K frames/packets and `2*M` PCM bytes. Both final progress frame counts, metadata row populations and capture bytes must agree. Priming is 1024 samples and final fill is `1024*ceil(N/1024)-N`; neither is silently dropped from evidence.

Native source reviews must examine these equalities against actual format/codec implementation. The JavaScript arithmetic is not evidence of an unobserved native execution. Full terminal/EOF, source/feed provenance, stack identity, initialized graph and full byte inventories remain independent premises.

## Full replay, clock and marker closure

`inspectProgramClock` only accepts a handle in `inspectCheckedProgram`'s private WeakMap, then binds PCM/RGB bytes and exact audio/video metadata hashes, populations and sequence. Its common 720000-Hz domain has audio origin `firstAudioPTS*15` and video origin `firstVideoPTS*8`; `quantum=0` and exact mode do not remove conditional stack assurance. `assertProgramClock` requires the private certificate and retains pending outer admission and both strong false flags. Literal clock mode cannot certify an encoded source.

`replayProgramRecording` independently consumes the complete original catalog, reopens/revalidates loaded implementation and both acquired bindings, regenerates noise/source/feed, runs all conservation guards, reconstructs the clock and recomputes visual and audio detector/classifier facts. It compares all serialized assurance copies, projections, raw rows, ranges, stream identities, format, coverage and episodes. It permits the existing explicit negative episode-bound case only with the corresponding independent failure; it cannot delete facts to fit a cap. Source observations, native packet metadata and reference detector outputs are compared, not substituted for one another.

The outer reader independently verifies the exact UTF-8 JSON-plus-LF result original, real A's prelaunch timestamp and exact audit set, K/source/code possession, I/C/Q/L/image joins, collector original inventory, two-read retrieval records, actual stopped/exit/definition/ENI cleanup and the complete R94 R/O reservation arithmetic. Local replay with no actual outer resolver/ledger returns pending work. `assertReplayedProgram` detects mutation after its private registration. No serialized kind or fixture effect supplies a genuine accepted handle.
