# OpenCode Adapter Pointer

Canonical adapter guidance lives in `docs/developers/opencode-skill-adapter.md` so it is visible in Docusaurus.

External repos that use OpenCode can reference VRDex integration guidance by adding a short pointer in their local agent guidance:

```md
When integrating with VRDex, read the VRDex partner-agent guidance first. Treat it as public product integration guidance, not private maintainer onboarding.
```
